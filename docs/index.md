# Studio Peta Palestina '48

Studio Peta adalah alat di browser untuk membuat **framing dan animasi peta** video sejarah Palestina. Hasilnya bisa langsung berupa video, atau gambar yang diedit lebih lanjut di Canva dan CapCut.

[Buka Studio :lucide-map:](https://studio.komnaspalestina.org/){ .md-button .md-button--primary }
[Mulai cepat](panduan/mulai.md){ .md-button }

## Rambu penamaan

- **Palestina '48** adalah seluruh wilayah Mandat Inggris atas Palestina. Wilayah yang dikuasai sejak 1948 tetap dilabeli sebagai bagian dari Palestina '48.
- **Golan** adalah wilayah Suriah. Golan tidak ikut diarsir sebagai Palestina dan punya layer arsir tersendiri.
- Label memakai bahasa Indonesia, dengan nama Arab di bawahnya (opsional).

## Apa saja yang bisa dibuat

<div class="grid cards" markdown>

-   :lucide-clapperboard: **Animasi kamera**

    Zoom dari Indonesia ke Timur Tengah lalu ke Gaza. Proyeksinya bisa globe, Mercator, atau otomatis.

-   :lucide-history: **Era sejarah**

    Dari Sykes-Picot 1916 sampai Garis Kuning Gaza 2026, lengkap dengan legenda dan judul tahun.

-   :lucide-layers: **SVG per layer untuk Canva**

    Setiap layer dipisah ke file SVG sendiri, jadi tetap tajam di zoom berapa pun.

-   :lucide-film: **Video dari browser**

    Video MP4 (H.264) atau WebM, dengan bingkai 16:9, 9:16, 4:3, 1:1, dan 4:5.

</div>
