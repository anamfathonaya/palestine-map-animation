# Mulai cepat

Alur paling singkat untuk membuat video zoom peta:

1. **Pilih bingkai** di panel *Bingkai & proyeksi*, misalnya 9:16 untuk Reels/TikTok. Kotak safe zone hanya tampil di pratinjau dan tidak ikut terekspor.
2. **Pilih preset** di panel *Kamera & preset*, misalnya "Timur Tengah → Palestina '48" atau "Linimasa 1916 → 1995".
3. Tekan **Putar** di bawah panggung untuk melihat animasinya. Geser slider untuk melompat ke detik tertentu.
4. **Ubah seperlunya.** Geser peta untuk memindah kamera dan scroll untuk zoom, lalu tekan *Simpan kamera ke terpilih* pada keyframe yang aktif.
5. Klik **Ekspor → Render video di browser**. File MP4 akan terunduh setelah render selesai.

!!! tip "Pakai Chrome atau Edge versi terbaru"
    Ekspor MP4 memakai WebCodecs. Kalau browser tidak mendukungnya, Studio otomatis beralih ke WebM, dan kalau WebM juga tidak bisa, ke perekaman waktu nyata.

## Kontrol peta

| Aksi | Hasil |
|---|---|
| Seret peta | Memindah kamera (bujur/lintang) |
| Scroll / tombol + − | Zoom (lebar bingkai dalam km) |
| Kolom *Bujur, Lintang, Lebar (km)* | Mengatur kamera secara presisi |
| *Lompat ke* | Langsung menuju area siap pakai (Gaza, Tepi Barat, Al-Quds, dll.) |

Semua pengaturan tersimpan otomatis di browser, jadi pekerjaan masih ada saat halaman dibuka lagi.
